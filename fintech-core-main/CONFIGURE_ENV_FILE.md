## Step-by-Step Configuration

### 1. Open Your .env File

```powershell

# Open .env in your text editor (Notepad, VS Code, etc.)
notepad .env
```

### 2. Update MongoDB Configuration Section

**FIND this section in your `.env` file:**

```ini
# MongoDB Configuration
# Note: MongoDB is NOT installed - will attempt localhost connection
MONGODB_URI=mongodb://localhost:27017/
MONGODB_DB_NAME=finance_advisor
```

**REPLACE with your Atlas connection string:**

```ini
# MongoDB Configuration
# Atlas connection string (replace with YOUR actual connection string)
MONGODB_URI=mongodb+srv://YOUR_USERNAME:YOUR_PASSWORD@YOUR_CLUSTER.mongodb.net/?retryWrites=true&w=majority
MONGODB_DB_NAME=finance_advisor
```

### 5. Important Notes

#### ⚠️ Special Characters in Password

If your password contains special characters, URL-encode them:

| Character | Encoded |
|-----------|---------|
| `@` | `%40` |
| `#` | `%23` |
| `:` | `%3A` |
| `/` | `%2F` |
| `?` | `%3F` |
| `%` | `%25` |

**Example:**
- Password: `p@ss:word#123`
- Encoded: `p%40ss%3Aword%23123`
- Full URI: `mongodb+srv://user:p%40ss%3Aword%23123@cluster0...`

#### ✓ Security Checklist

- [ ] Connection string copied from Atlas dashboard
- [ ] Password placeholder `<password>` replaced with actual password
- [ ] No angle brackets `< >` in the connection string
- [ ] `.env` file is NOT tracked by Git (check `.gitignore`)
- [ ] Never paste your connection string in chat, email, or public forums

#### 🔒 What to Keep Secret

**NEVER SHARE:**
- ✗ Your database password
- ✗ Your complete connection string
- ✗ Your `.env` file contents

**SAFE TO SHARE:**
- ✓ Cluster hostname (e.g., `cluster0.abc123.mongodb.net`)
- ✓ Database name (`finance_advisor`)
- ✓ Username (`fincore_user`) - though not recommended

## Troubleshooting

### Issue: "MONGODB_URI not set"
**Solution:** Check for typos in variable name, ensure no extra spaces

### Issue: File not saving changes
**Solution:** 
- Check file isn't read-only
- Run text editor as administrator
- Ensure file path is correct

### Issue: Connection string not working
**Solution:**
- Verify no spaces at beginning/end of line
- Check password is URL-encoded if it has special chars
- Ensure connection string is on ONE line (no line breaks)
